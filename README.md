Sunset Panels — a multi-panel GTA-style cover art maker. Load your own photos, crop and position each into poster panels (one photo across panels or a different photo per panel), grade them with a Vice City sunset/neon duotone, halftone and film grain, type an editable bold caption with a tagline, and export a PNG in the 1080x1080, 1080x1350 and 1920x1080 post sizes. Plain static files, canvas-based, no build step, works offline; photos never leave your machine.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080, load photos (or the bundled samples), pick a template, and hit **Export PNG**.
